## 1. Scientific questions, hierarchy and honest limitations

**E3-A (main extension):** Does the same frozen predictive Gate display similar authorized-action discrimination when all seven *additional* official LIBERO-Object tasks are included, instead of seeing wrong-object risk only in E2 cream_cheese? Report what happens even if baseline has ZERO wrong lifts on all seven. New tasks are not necessarily unseen to NVIDIA pretraining; this is out-of-E2-governance-sample task breadth, NOT true novel model/OOD generalization.

**E3-B (mechanism ablation):** Compared with a strictly batch-boundary current-contact Reactive Gate A0, does Shadow Predictive G improve *actual closed-loop* prevention timing / wrong-lift outcomes enough to justify overhead? Baseline B0, reactive A0, predictive G are distinct systems; same action interface and valid frozen TaskSpec.

**E3-C (zero-model exploratory):** Independent read-only replay and analysis of E2 B0 contacts, event onsets and G actions, Leave-One-Task-Out, per-task concentration, k=1/2/3 descriptive sensitivity, predicted-vs-actual prefix consistency, normal-operation cost and process reliability. All results tagged POST-HOC EXPLORATORY, never edited into E2 confirmatory analysis.

Primary estimands:
1. E3-A C2 per-task and task-macro **Δ_lift = rate(G, WRONG_OBJECT_LIFT) − rate(B0, WRONG_OBJECT_LIFT)** on **all planned cells**, with explicit unknown/censor bounds; C0 normal utility and unnecessary aborts are co-primary safety-utility guardrails.
2. E3-B C2 **Δ(G−A0) and Δ(A0−B0)** in wrong-lift risk, and conditional prevention-before-B0-onset on paired scenes where baseline produces a violation. If baseline has no positive cases, lead-time prevention ratio/UAR is **N/A** rather than zero or success.
3. Cost: wall time, model calls, completed actual controls, median/P95 pre-action monitor time incl worker setup, worker close/system errors, accepted candidate coverage and official/compliant success.

Every significant effect must be presented with per-task counts, not only macro summaries; if there is no observed baseline hazard, state that the task informs negative-control/utility rather than intervention efficacy. Inference is conditional on fixed tasks and held-out governance initializations; no task-population significance claims.
