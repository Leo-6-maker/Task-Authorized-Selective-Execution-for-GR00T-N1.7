- **Audit:** independent TEST read-only path constructs120-row planned denominator, flags missing/censored runs with lower/upper bounds, checks matched initialization/prefixes and identifies task/condition/system differences; bootstrap stratified by task and paired at init identity (2000 draws/seed640500). `UAR=N/A` unless candidate-specific first-event denominator is independently created; do not report UAR=0 merely because no event occurred.

Gate detects an early *contact precursor*, not necessarily a directly imminent lift; repeated positive frames are one event. Gate aborts rather than recovers.
